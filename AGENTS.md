# Codane engineering contract

Read CODANE_HARNESS_REQUIREMENTS.md completely before editing.

Rules:

1. Work from the exact current repository state.
2. Preserve useful existing Codane work where compatible.
3. Use incremental TDD.
4. Never weaken tests to obtain green.
5. Do not call real Codex from automated tests.
6. Do not push.
7. Do not reset, clean, stash, restore, or discard legitimate work.
8. Keep runtime C++20 and dependency-light.
9. Success requires machine-verifiable execution evidence.
10. If something remains incomplete, report it explicitly.
